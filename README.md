# Booksville Books — system design

My system-design contribution to a group project for COM155 Business Information Systems at Ulster University, 2025/26.

## My contribution

I explained how the menu, Python functions and shared book list work together, mapped menu choices to features, and presented the search-and-stock-update flow.

## Group prototype

The prototype supports inventory listing, adding and finding books, stock adjustments, author sorting and summary reports.

## Design decisions and limitations

- Separate functions handle the menu options.
- A shared list holds the book records.
- Reports calculate stock value, average price and titles by genre.
- Changes remain in memory during the session.
- File or database storage would be a future improvement.
